# 🌤 Weather App

A simple Weather App built using HTML, CSS and JavaScript with API integration.

## 🚀 Features
- Search weather by city
- Displays temperature
- Shows humidity and wind speed
- Real-time weather data using API

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- WeatherAPI

## 🔑 API Used
WeatherAPI - https://www.weatherapi.com/
